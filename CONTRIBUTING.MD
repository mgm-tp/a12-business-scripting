# Contributing to A12 Platform

Thank you for your interest in contributing to A12 Platform, an open source project maintained by mgm technology partners. We appreciate your engagement and commitment to helping us make A12 better for everyone!

## Dual License Notice

Please note that A12 is made available under a dual licensing model. For details about licensing, please refer to LICENSE and documentation within this repository.

## Current Status: Read-Only Repository

A12 is undergoing a carefully planned open source transition. This process goes beyond simply publishing the code:
- **Comprehensive review:** Both technical and legal aspects of the platform must be reviewed and addressed to ensure that contribution and usage comply with required standards.
- **Decoupled build process:** One key focus is adapting and documenting the build processes so that A12 can be built independently of any specific enterprise development environment.
- **Infrastructure preparation:** We are updating our CI/CD and release infrastructure to facilitate external collaboration.

The repository is provided as **read-only**, and is updated by the core development team on a regular basis. **Direct code contributions (pull requests or patches) are not yet accepted.**

## How You Can Help Now

Even while the repository is read-only, your feedback is invaluable:
- **Bug Reports:** If you identify any bugs, please open an issue describing the problem, steps to reproduce, and the affected version or component.
- **Feature Requests:** Suggest enhancements or new features by filing a feature request via the issue tracker.
- **Discussions:** Connect with other users and discuss usage scenarios, best practices, or questions via the discussion forum available at GetA12.com.

Our team monitors all tickets and will collect your input as we move towards an open contribution model.

## Thank You!

We are grateful for your interest as we work to ensure that A12’s open source process is robust, transparent, and ready for community engagement. Your participation—even just through feedback and discussion—is essential as we lay the foundation for a vibrant project!

For more information and updates, please refer to the documentation at **GetA12.com**.
